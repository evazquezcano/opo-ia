## Fallos de calidad y riesgos pendientes (no resueltos)

1. **Vigencia**: no se ha realizado lectura de la situación jurídica de todas las disposiciones, derogatorias, transitorias, correcciones ni normas sobrevenidas. Ninguna de las 51 combinaciones puede calificarse «auditoría integral completa».
2. **Organización**: resolver una a una las referencias supletorias al RD 83/1996 donde aparecen, considerando titularidad, etapa y normas autonómicas propias.
3. **Cobertura normativa**: falta completar y contrastar para cada territorio las normas de evaluación, inclusión, convivencia, funcionamiento, optativas, programas e instrucciones del curso escolar 2026-2027. Tener una norma complementaria no significa cubrir cada categoría.
4. **Enlaces**: no se ha realizado comprobación HTTP sistemática de todos los enlaces, ni revisión minuciosa de cada título literal y publicación individual. No utilizar una URL deducida o no contrastada como si fuera oficial.
5. **APA 7**: presentación jurídica aproximada, sin verificación editorial norma a norma.
6. **Exportación**: el código para Word y PDF existe y las pruebas simuladas pasan, pero queda pendiente el cotejo visual y funcional de archivos reales.
7. **Publicación**: GitHub Actions notificó despliegue correcto; la herramienta de consulta web no permite verificar por sí misma la respuesta HTTP de GitHub Pages. Comprobar la interfaz desde el navegador del usuario.
